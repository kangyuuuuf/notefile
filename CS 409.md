### What is HTML?

**Hypertext:** text that contains links to other texts

#### Common Tages

```html
<div> 				// group elements spanning multiple lines line break before and after
<span>				// group elements within a single line
<p>						// new paragraph
<br>					// line break
  
<h1>,...,<h6>	// headings
<img src=''>	// images
<a href=''>		// hyperlinks
  
<table><tr><td>		// tables
<ul><li>					// unordered list
<ol><li>					// ordered list
  
<title>				set title that appears in browser
<link>				include CSS stylessheets
<script>			embed javascript
  
```

**Document Object Model:** One-to-one correspondence between HTML elements and DOM nodes

**Standards: **

-   Internet Engineering Task Force(IETF)
-   World Wide Web Consortium(W3C)
-   Web Hypertext Application Technology Working Group(WHATWG)

#### A Tale of Two Working Groups

**Towards a cleaner web: ** Web browsers have forgiving parsers 99% of pages have at least one error Move HTML from SGML to stricter XML. **X for extensibility**

**XHTML Syntax:** 

-   All tags must be closed: \<p\>…\</p\>, \<br/\> 
-   lower case tags
-   quotes around attribute values

**XHTML Loophole:** 

-   set **DOCTYPE** to **XHTML**, **MIME** type to text/HTML
-   upgrade to **XHTML** syntax
-   Browsers interpret documents as HTML
-   Loophole closed in XHTML 1.1

**HTML5**: successor to HTML 4.01 and XHTML 1.1 not based on SGML; backwards compatible.
